# Waypoint AI Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Manage Servers: connect to Waypoint servers, sign in, and switch between them.
- Browse Sessions: find sessions, chat with them, and rename, pin, reattach, interrupt, terminate, or delete them; ⌘N opens New Chat.
- Quick Chat and New Chat: chat with coding agents, with timed reuse, multiline composition, selected text, clipboard, and attachments.
- Answer approvals, plans, and questions natively.
- Edit a session's settings, with restart and interruption previews.
- Show effective preset and agent defaults in launch and session settings while preserving inheritance.
- Use for Quick Chat: make a session found in Browse Sessions Quick Chat's destination, when it has a native conversation that can continue.
- Quick Chat sessions are titled with their creation time, start in a scratch workspace when the server runs on this Mac, and can be terminated or deleted from Quick Chat.
- New Session with Settings: start a Quick Chat session from chosen settings without changing Quick Chat Defaults.
- Consecutive tool calls collapse into a summary line in conversations and Conversation History, and expand to each call's target and change counts.
